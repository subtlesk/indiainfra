How this is built — sources, checks & honest limits

Every number on this page is parsed from an archived primary-source government file — never typed in from memory. The build recomputes the whole page from those files and runs identity checks (do the parts sum to the whole? does the same figure agree across two independent documents?). If any check fails, the site does not publish.

    Where India's own published tables don't add up (they sometimes don't), the difference is shown as a "residual" — published, never hidden. Full model: chain specification v0.2 on GitHub.
